# Code Of Conduct

Core Framework aims to be a practical, respectful open-source project. Be direct, technical, and considerate.

## Standards

Expected behavior:

- focus criticism on code, design, documentation, and tradeoffs
- assume good intent while remaining precise about problems
- respect maintainers' and contributors' time by keeping issues and pull requests focused
- welcome people with different backgrounds, experience levels, and perspectives
- avoid sharing private project data, site information, or credentials

Unacceptable behavior:

- insults, threats, stalking, harassment, or sustained disruption
- discriminatory or sexualized language or imagery
- publishing private information without permission
- bad-faith reports, spam, or coordinated abuse

## Enforcement

Maintainers may edit or delete comments, close issues, reject pull requests, block users, or take other moderation action needed to keep the project usable.

For conduct concerns, contact `hello@coreframework.com`. Do not include sensitive personal details in a public issue.
